# CS2 MVOU Tournament

Статический сайт турнира с публичной страницей, открытой панелью редактирования и синхронизацией через Supabase Realtime.

## Структура

- `index.html` — публичный экран турнира.
- `admin.html` — редактирование команд и результатов.
- `assets/styles.css` — общий адаптивный интерфейс.
- `js/data.js` — правила турнира и расчёт сетки.
- `js/render.js` — безопасный рендер публичной и административной страниц.
- `js/supabase.js` — загрузка, конкурентное сохранение, Realtime и Storage.
- `js/config.js` — публичные параметры проекта Supabase.
- `supabase/schema.sql` — таблица, RLS, Realtime, Storage и пустой турнир.

## Формат турнира

Групповой этап — круговой BO1 для пяти команд. Четыре команды с наибольшим количеством побед выходят в полуфиналы BO3. Победители полуфиналов играют финал BO3, проигравшие — матч за третье место BO3.

## Безопасность

Сайт использует только publishable key. Политики RLS разрешают публично читать и обновлять единственную строку `main`, но запрещают вставку и удаление строк. JSON ограничен 128 КБ и проверяется по базовой структуре. Ревизия изменяется триггером и защищает от тихой перезаписи параллельных правок. Storage принимает только пять фиксированных WebP-путей и файлы до 1 МБ. CSP ограничивает внешние скрипты, подключения, изображения и iframe утверждёнными источниками.

Открытое редактирование означает, что любой человек, получивший URL панели, технически может менять результаты. Для настоящего ограничения сотрудниками потребуется подключить Supabase Auth и корпоративный домен.
